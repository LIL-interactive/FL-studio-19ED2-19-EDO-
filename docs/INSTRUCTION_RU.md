# Инструкция: 19-EDO (19ED2) в FL Studio, опционально A = 437 Гц

## 0. Как это устроено (прочитать один раз)

- 19-EDO — октава делится на 19 равных шагов по 63,158 цента (в 12-TET полутон = 100 центов).
- Раскладка во всём наборе одна и та же — линейная: каждая клавиша Piano roll / MIDI-клавиатуры
  = следующий шаг 19-EDO. Октава занимает 19 клавиш, а не 12.
- Опорная клавиша — MIDI 69. В FL Studio она подписана A5 (FL нумерует октавы на одну выше
  MIDI-стандарта), в других программах — A4. Она звучит на 440 Гц или 437 Гц (по выбору).
- Названия нот 19-EDO на клавишах (для A = клавиша 69):

| Клавиша (MIDI) | Подпись в FL | Нота 19-EDO |
|---|---|---|
| 55 | G4 | C4 |
| 56 | G#4 | C#4 |
| 57 | A4 | Db4 |
| 58 | A#4 | D4 |
| 59 | B4 | D#4 |
| 60 | C5 | Eb4 |
| 61 | C#5 | E4 |
| 62 | D5 | E#/Fb4 |
| 63 | D#5 | F4 |
| 64 | E5 | F#4 |
| 65 | F5 | Gb4 |
| 66 | F#5 | G4 |
| 67 | G5 | G#4 |
| 68 | G#5 | Ab4 |
| 69 | A5 | A4 |
| 70 | A#5 | A#4 |
| 71 | B5 | Bb4 |
| 72 | C6 | B4 |
| 73 | C#6 | B#/Cb4 |
| 74 | D6 | C5 |

  Полная таблица с частотами — presets/A440/19-EDO_A440_table.csv и presets/A437/19-EDO_A437_table.csv.

Каждому типу инструмента нужен свой способ (у FL нет глобального строя), но все способы ниже дают
одинаковые частоты, поэтому в одном проекте их можно смешивать.

| Инструмент в проекте | Способ | Раздел |
|---|---|---|
| Родные генераторы FL (FLEX, Sytrus, 3xOsc, FPC, Sampler, GMS, Harmor…) | VFX Script | [1](#1-родные-инструменты-fl-studio--vfx-script) |
| Kontakt (любые библиотеки) | KSP-скрипт | [2](#2-kontakt--ksp-скрипт) |
| VST/VST3/CLAP с поддержкой MTS-ESP | MTS-ESP Mini + .scl/.kbm | [3](#3-все-mts-esp-совместимые-плагины-сразу) |
| VST с импортом .scl/.kbm/.tun | файлы из presets/ | [4](#4-плагины-с-импортом-scl--kbm--tun) |
| Железо / плагины с MIDI Tuning Standard | .syx | [5](#5-mts-sysex) |
| Быстрый черновик без плагинов | Piano roll script | [6](#6-запасной-путь-piano-roll-script) |

## 1. Родные инструменты FL Studio — VFX Script

Нужен FL Studio 2024 (21.2+) с плагином VFX Script.

1. Добавьте в Channel rack Patcher (или замените инструмент канала на Patcher).
2. Внутри Patcher добавьте VFX Script и нужный инструмент (например FLEX).
3. Соедините: вход Patcher (From FL Studio, ноты) → VFX Script → инструмент → выход (To FL Studio).
   Подсказка: правый клик по иконке VFX Script в Patcher → выбрать цель.
4. Откройте VFX Script → редактор кода → вставьте целиком fl_studio/VFX Script/19-EDO Retuner.py → Compile/Apply.
5. В окне скрипта:
   - A4 reference — 440 Hz или 437 Hz (или Custom (knob) + ручка Custom A4 (Hz));
   - Reference key (A) — 69 (A5 в FL). Можно сдвинуть, если удобнее держать A на другой клавише;
   - Bypass — мгновенно вернуть 12-TET для сравнения.
6. Сохраните весь Patcher как пресет (меню пресетов → Save preset as… «19-EDO FLEX») — дальше
   просто перетаскивайте его на новые каналы.

Слайды и портаменто из Piano roll работают: скользят по шагам 19-EDO.

Для сторонних VST внутри Patcher дробная высота ноты из VFX Script передаётся только если сам плагин
поддерживает per-note pitch (VST3 Note Expression / CLAP). Проверьте на слух по таблице частот; если
плагин играет 12-TET — используйте разделы 2–4.

## 2. Kontakt — KSP-скрипт

Работает в Kontakt 5/6/7/8 со всеми библиотеками, включая заблокированные (свободный слот
скрипта есть почти всегда).

1. Откройте Kontakt, загрузите инструмент.
2. Нажмите гаечный ключ (Instrument Edit) → вкладка Script Editor.
3. Выберите последний пустой слот (справа от скриптов библиотеки — так перестраиваются уже
   готовые ноты библиотеки, а её keyswitch/legato-логика видит исходные клавиши).
4. Edit → вставьте текст из:
   - kontakt/19-EDO_Tuner.ksp.txt — по умолчанию A = 440 Гц;
   - kontakt/19-EDO_Tuner_A437.ksp.txt — по умолчанию A = 437 Гц.
5. Apply, закройте гаечный ключ. Появится панель 19-EDO Tuner:
   - A4 — 440 / 437 / 432 / 442 / 415 Гц;
   - Mode:
     - Remap + fine tune (по умолчанию, лучшее качество) — нота переносится на ближайшую 12-TET клавишу
       и доводится максимум на ±50 центов, т. е. используется ближайший сэмпл без «мультяшности»;
     - Tune in place — клавиша не меняется, только высота. Включите, если библиотека с legato/
       round-robin-скриптом ведёт себя странно в режиме Remap;
   - RefKey — клавиша A (69);
   - Bypass — вернуть 12-TET.
6. Сохраните: Files → Save as… (инструмент/Multi) или Script → Save preset в Script Editor,
   чтобы потом подгружать одним кликом.

Важно: в самом Kontakt/библиотеке общий Tune должен быть 0 и Master Tune = 440 Гц — смещение
до 437 Гц делает скрипт. В Kontakt-мульти скрипт ставится в каждый инструмент.

## 3. Все MTS-ESP-совместимые плагины сразу

1. Скачайте бесплатный ODDSound MTS-ESP Mini (https://oddsound.com) и установите.
2. В FL Studio поставьте MTS-ESP Mini в любой слот (например на Master) — один на проект.
3. В MTS-ESP Mini: Load → presets/A437/19-EDO.scl и presets/A437/19-EDO_A437.kbm
   (или из presets/A440/).
4. Все совместимые плагины в проекте (Surge XT, Vital, Pigments, u-he, Serum 2 и др. — список на
   https://oddsound.com/supportedplugins.php) перестроятся автоматически; в некоторых нужно
   включить «MTS-ESP / Use tuning from master» в настройках плагина.

Это самый «глобальный» путь: смена .kbm 440 ↔ 437 в одном месте перестраивает весь проект.

## 4. Плагины с импортом .scl / .kbm / .tun

В настройках строя плагина (Tuning / Microtuning / Scala) загрузите:

- .scl — presets/A4xx/19-EDO.scl (сам строй);
- .kbm — presets/A4xx/19-EDO_A4xx.kbm (раскладка: клавиша 69 = A = 440/437 Гц).
  Без .kbm многие плагины поставят начало строя на C (клавиша 60) и A будет «плыть» — загружайте оба файла;
- если плагин понимает только .tun — presets/A4xx/19-EDO_A4xx.tun.

## 5. MTS SysEx

presets/A4xx/19-EDO_A4xx.syx — MIDI Tuning Standard Bulk Dump (128 нот, программа 0, device 7F).
Отправьте на синтезатор через SysEx-утилиту (или MIDI Out FL Studio, если синт принимает SysEx),
затем выберите на синтезаторе tuning-программу 0.

## 6. Запасной путь: Piano roll script

Подходит для быстрого черновика на любом канале, который учитывает Note fine pitch
(родные генераторы FL). Точность ±5 центов (ограничение FL: fine pitch хранится шагами по 10 центов).

1. Скопируйте fl_studio/Piano roll scripts/19-EDO Convert.pyscript в
   Документы\Image-Line\FL Studio\Settings\Piano roll scripts\.
2. Напишите партию «по шагам 19-EDO» (раскладка из раздела 0).
3. Piano roll → меню Scripts → 19-EDO Convert → выберите A (440/437), опорную клавишу, ноты → OK.
4. Ноты переедут на ближайшие 12-TET клавиши с нужным fine pitch. Отмена — Ctrl+Z.
   Не применяйте скрипт повторно к уже сконвертированным нотам.

Если пользуетесь VFX Script (раздел 1), этот скрипт не нужен — VFX Script перестраивает «на лету»,
а ноты остаются в удобной 19-EDO раскладке.

## Свой эталон A или опорная клавиша

Нужен, например, A = 435 Гц или A на клавише 57:

```bash
python3 tools/edo19.py --a4 435 --ref-key 69 --out presets/A435 --ksp kontakt/19-EDO_Tuner_A435.ksp.txt
```

В VFX Script и Piano roll script частота задаётся ручкой Custom A4 (Hz) без генерации.

## Проверка, что всё строит правильно

1. Поставьте на Master Fruity Spectroman или любой тюнер (например бесплатный GTune / MTuner).
2. Нажмите клавишу 69 (A5 в FL) — должно быть 440,00 или 437,00 Гц.
3. Клавиша 69 + 19 = 88 — ровно вдвое выше (880 / 874 Гц).
4. Клавиша 70 — 456,35 Гц (A = 440) или 453,24 Гц (A = 437). Остальные значения — в CSV-таблице.

Автотесты математики и форматов: python3 -m unittest discover -s tests -v.

## Частые проблемы

| Симптом | Причина / решение |
|---|---|
| Kontakt звучит в 12-TET | Скрипт не применён (Apply) или включён Bypass; скрипт стоит в слоте, но библиотека игнорирует события — переставьте в последний слот. |
| Kontakt: залипающие/двойные ноты, сломанное legato | Переключите Mode → Tune in place. |
| Плагин после .scl строит от C, а не от A | Не загружен .kbm. |
| В VFX Script сторонний VST не перестраивается | Плагин не поддерживает per-note pitch — используйте MTS-ESP / .scl / KSP. |
| Аккорды «кривые» в 19-EDO | Помните: октава = 19 клавиш. Большая терция = 6 шагов, малая = 5, квинта = 11. |
