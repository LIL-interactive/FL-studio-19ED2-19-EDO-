# 14. Словарь терминов

Термины расположены по алфавиту: сначала русские, затем английские. В скобках — номер гайда, где тема разобрана подробнее.

---

## А–Я

| Термин | Объяснение |
|---|---|
| Аккорд | Три и более нот, звучащих одновременно (01) |
| Аранжировка | Распределение музыкального материала по инструментам и времени (05) |
| Артикуляция | Способ извлечения звука: legato, staccato, pizzicato и т. д. (06) |
| Бэкбит | Акцент на слабые доли 2 и 4, обычно малый барабан (04) |
| Вертикальное наслоение | Адаптивная музыка из синхронных слоёв, которые игра включает и выключает (10) |
| Вторичная доминанта | Доминанта к любому аккорду, кроме тоники: например A7 → Dm в до мажоре (02) |
| Голосоведение | Правила соединения аккордов так, чтобы голоса двигались плавно (02) |
| Горизонтальное ре-секвенирование | Адаптивная музыка из секций, которые игра выбирает по ситуации (10) |
| Грув | Ощущение «качания» ритма: тайминг, динамика, свинг (04) |
| Децибел (дБ) | Логарифмическая единица уровня; +6 дБ — примерно удвоение амплитуды (08) |
| Диапазон | Расстояние между самой низкой и самой высокой нотой инструмента или мелодии (03, 06) |
| Диез / бемоль | Повышение / понижение ноты на полутон (в 19-EDO — на 1 шаг) (01, 12) |
| Доминанта | Аккорд V ступени, создаёт напряжение и стремится в тонику (02) |
| Заимствованный аккорд | Аккорд из параллельной тональности: Fm в до мажоре (02) |
| Интервал | Расстояние между двумя нотами (01) |
| Каденция | Гармонический оборот, завершающий фразу (02) |
| Квантизация | Выравнивание нот по сетке (04) |
| Кейсвитч | Нота вне диапазона инструмента, переключающая артикуляцию (06) |
| Компрессор | Устройство, уменьшающее разницу между громкими и тихими звуками (08) |
| Контрмелодия | Вторая мелодия, отвечающая главной (05) |
| Лад | Набор ступеней с определённым характером: мажор, минор, дорийский и т. д. (01, 02) |
| Лейтмотив | Короткая тема, закреплённая за персонажем, местом или идеей (03, 10) |
| Лимитер | Компрессор с очень высоким соотношением, не даёт сигналу превысить потолок (09) |
| Луп | Фрагмент, повторяющийся по кругу (10) |
| Мастеринг | Финальная подготовка трека к выпуску: тон, громкость, формат (09) |
| Маскировка | Ситуация, когда один звук «закрывает» другой в той же частотной области (08) |
| Медианта хроматическая | Аккорд на терцию выше или ниже, часто с одной общей нотой: C → E, C → Ab (02) |
| Модуляция | Смена тональности (02) |
| Мотив | Самая маленькая узнаваемая музыкальная идея, 2–6 нот (03) |
| Обертоны (гармоники) | Дополнительные частоты в звуке, определяющие тембр (07) |
| Обращение аккорда | Аккорд, в басу которого не основной тон: C/E (01) |
| Огибающая (ADSR) | Изменение параметра во времени: атака, спад, удержание, затухание (07) |
| Октава | Интервал с удвоением частоты; та же нота выше или ниже (01) |
| Остинато | Повторяющаяся мелодическая или ритмическая фигура (02, 06) |
| Панорама | Положение звука между левым и правым каналом (08) |
| Педаль (органный пункт) | Долгая нота в басу, над которой меняются аккорды (02) |
| Период | Две фразы (вопрос и ответ), обычно 8 тактов (03) |
| Полутон | Самый маленький шаг в 12-TET: соседние клавиши (01) |
| Пентатоника | Гамма из пяти нот без полутонов (01) |
| Размер | Количество и длительность долей в такте: 4/4, 3/4, 7/8 (01, 04) |
| Ревер (реверберация) | Эффект пространства: отражения звука от стен (08) |
| Резонанс | Подъём на частоте среза фильтра или «свистящая» частота в звуке (07, 08) |
| Референс | Готовый трек, с которым сравнивают свою работу (08, 09) |
| Сайдчейн | Управление обработкой одного звука сигналом другого: бас приглушается от бочки (04, 08) |
| Сатурация | Мягкое искажение, добавляющее гармоники и плотность (08) |
| Свинг | Смещение каждой второй восьмой или шестнадцатой позже (04) |
| Секвенция | Повтор мотива от другой ступени (03) |
| Синкопа | Акцент между долями (04) |
| Стем | Отдельная дорожка или группа дорожек, экспортированная в файл (10) |
| Стингер | Короткая музыкальная фраза-сигнал в игре (10) |
| Строй | Правило выбора частот нот: 12-TET, 19-EDO, натуральный строй (12) |
| Субдоминанта | Аккорд IV ступени, «уход из дома» (02) |
| Такт | Группа долей между двумя сильными долями (01) |
| Тембр | «Окраска» звука, по которой различают инструменты (07) |
| Темп | Скорость музыки в ударах в минуту (BPM) (01) |
| Тоника | Главная, устойчивая нота или аккорд тональности (01, 02) |
| Тональность | Тоника + лад: например ре минор (01) |
| Тритон | Интервал в 6 полутонов, самый неустойчивый (01) |
| Трезвучие | Аккорд из трёх нот, построенный терциями (01) |
| Фильтр | Устройство, пропускающее одни частоты и срезающее другие (07) |
| Фраза | Законченная музыкальная мысль, обычно 2–4 такта (03) |
| Цент | 1/100 полутона 12-TET; 1200 центов в октаве (12) |
| Эквалайзер (EQ) | Устройство для изменения громкости отдельных частот (08) |

## A–Z

| Термин | Объяснение |
|---|---|
| ADSR | Attack, Decay, Sustain, Release — параметры огибающей (07) |
| BPM | Beats per minute — темп (01) |
| CC1, CC11 | MIDI-контроллеры динамики и выразительности в оркестровых библиотеках (06) |
| Clipping | Перегрузка: сигнал выше 0 dBFS обрезается (08, 09) |
| dBFS | Децибелы относительно цифрового максимума (0 dBFS) (09) |
| dBTP (True Peak) | Реальный пик сигнала с учётом межсэмпловых пиков (09) |
| Dither | Добавление слабого шума при уменьшении разрядности (24 → 16 бит) (09) |
| EDO | Equal division of the octave — равномерное деление октавы (12) |
| FMOD | Middleware для игрового звука (10) |
| HPF / LPF | High-pass / Low-pass filter — обрезной фильтр низа / верха (07, 08) |
| LFO | Low-frequency oscillator — медленный генератор модуляции (07) |
| LRA | Loudness range — разброс громкости по треку (09) |
| LUFS | Единица воспринимаемой громкости (ITU-R BS.1770) (09) |
| MIDI | Протокол передачи нот и команд между устройствами и программами (01, 06) |
| Middleware | Программа между музыкой и движком игры: FMOD, Wwise (10) |
| MTS-ESP | Протокол перестройки множества плагинов одним мастер-плагином (12) |
| Patcher | Плагин FL Studio для сборки цепочек инструментов и эффектов (12) |
| PLR | Peak-to-loudness ratio — разница пика и громкости (09) |
| Re-score | Переозвучка видео своей музыкой для портфолио (13) |
| Round robin | Чередование нескольких вариантов одного звука (07) |
| Scala (.scl / .kbm) | Форматы файлов строя и раскладки клавиш (12) |
| Send | Посыл части сигнала на отдельную дорожку (ревер, дилей) (08) |
| Sidechain | См. «Сайдчейн» |
| Stem | См. «Стем» |
| Supersaw | Звук из нескольких расстроенных пил, классика EDM (07) |
| TET | Tone equal temperament — равномерно темперированный строй: 12-TET (12) |
| Velocity | Сила нажатия клавиши, обычно влияет на громкость и тембр (04, 06) |
| VST / VST3 / CLAP | Форматы подключаемых плагинов (08) |
| Wwise | Middleware для игрового звука от Audiokinetic (10) |
