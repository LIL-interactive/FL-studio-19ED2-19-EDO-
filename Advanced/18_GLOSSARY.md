# 18. Словарь терминов

Около 110 терминов курса расположены по алфавиту: сначала русские, затем английские. В скобках — номер модуля, где тема разобрана подробнее.

---

## А–Я

| Термин | Объяснение |
|---|---|
| Аккорд | Три и более нот, звучащих одновременно (03) |
| Акустическая ось | Линия, на которой монитор звучит точнее всего; по Genelec — на уровне ушей, 1,2–1,4 м от пола (15) |
| Аранжировка | Распределение музыкального материала по инструментам и времени (07) |
| Артикуляция | Способ извлечения звука: legato, staccato, pizzicato и т. д. (09) |
| Аудиация | Способность слышать и понимать музыку внутри себя без звука (01) |
| Басовая ловушка | Акустический поглотитель низких частот, обычно в углах или на стенах (15) |
| Буфер | Порция звука, которую компьютер готовит заранее; больше буфер — стабильнее работа, но больше задержка (15) |
| Бэкбит | Акцент на слабые доли 2 и 4, обычно малый барабан (06) |
| Вертикальное наслоение | Адаптивная музыка из синхронных слоёв, которые игра включает и выключает (12) |
| Вторичная доминанта | Доминанта к любому аккорду, кроме тоники: например A7 → Dm в до мажоре (04) |
| Голосоведение | Правила соединения аккордов так, чтобы голоса двигались плавно (04) |
| Горизонтальное ре-секвенирование | Адаптивная музыка из секций, которые игра выбирает по ситуации (12) |
| Грув | Ощущение «качания» ритма: тайминг, динамика, свинг (06) |
| Децибел (дБ) | Логарифмическая единица уровня; +6 дБ — примерно удвоение амплитуды (10) |
| Диапазон | Расстояние между самой низкой и самой высокой нотой инструмента или мелодии (05, 09) |
| Диез / бемоль | Повышение / понижение ноты на полутон (в 19-EDO — на 1 шаг) (03, 14) |
| Доминанта | Аккорд V ступени, создаёт напряжение и стремится в тонику (04) |
| Задержка (латентность) | Время между действием (нажатием клавиши) и звуком (15) |
| Заимствованный аккорд | Аккорд из параллельной тональности: Fm в до мажоре (04) |
| Интервал | Расстояние между двумя нотами (03) |
| Интервальные повторения | Повторение материала через нарастающие промежутки времени (01) |
| Каденция | Гармонический оборот, завершающий фразу (04) |
| Квантизация | Выравнивание нот по сетке (06) |
| Кейсвитч | Нота вне диапазона инструмента, переключающая артикуляцию (09) |
| Компрессор | Устройство, уменьшающее разницу между громкими и тихими звуками (10) |
| Контрмелодия | Вторая мелодия, отвечающая главной (07) |
| Лад | Набор ступеней с определённым характером: мажор, минор, дорийский и т. д. (03, 04) |
| Лейтмотив | Короткая тема, закреплённая за персонажем, местом или идеей (05, 12) |
| Лимитер | Компрессор с очень высоким соотношением, не даёт сигналу превысить потолок (11) |
| Луп | Фрагмент, повторяющийся по кругу (12) |
| Маскировка | Ситуация, когда один звук «закрывает» другой в той же частотной области (10) |
| Мастеринг | Финальная подготовка трека к выпуску: тон, громкость, формат (11) |
| Медианта хроматическая | Аккорд на терцию выше или ниже, часто с одной общей нотой: C → E, C → Ab (04) |
| Минъё | Японская народная песня; исполнительниц минъё Кэндзи Каваи пригласил для Ghost in the Shell (13) |
| Модуляция | Смена тональности (04) |
| Мотив | Самая маленькая узнаваемая музыкальная идея, 2–6 нот (05) |
| Обертоны (гармоники) | Дополнительные частоты в звуке, определяющие тембр (08) |
| Обращение аккорда | Аккорд, в басу которого не основной тон: C/E (03) |
| Огибающая (ADSR) | Изменение параметра во времени: атака, спад, удержание, затухание (08) |
| Октава | Интервал с удвоением частоты; та же нота выше или ниже (03) |
| Органум | Средневековое многоголосие: к мелодии хорала добавляется голос, движущийся параллельно; с ним сравнивают пары голосов у Кадзиуры (13) |
| Остинато | Повторяющаяся мелодическая или ритмическая фигура (04, 09) |
| Панорама | Положение звука между левым и правым каналом (10) |
| Педаль (органный пункт) | Долгая нота в басу, над которой меняются аккорды (04) |
| Пентатоника | Гамма из пяти нот без полутонов (03) |
| Период | Две фразы (вопрос и ответ), обычно 8 тактов (05) |
| Полутон | Самый маленький шаг в 12-TET: соседние клавиши (03) |
| Размер | Количество и длительность долей в такте: 4/4, 3/4, 7/8 (03, 06) |
| Ревер (реверберация) | Эффект пространства: отражения звука от стен (10) |
| Резонанс | Подъём на частоте среза фильтра или «свистящая» частота в звуке (08, 10) |
| Референс | Готовый трек, с которым сравнивают свою работу (10, 11) |
| Розовый шум | Шум с одинаковой энергией в каждой октаве; используется для калибровки громкости (15) |
| Сайдчейн | Управление обработкой одного звука сигналом другого: бас приглушается от бочки (06, 10) |
| Сатурация | Мягкое искажение, добавляющее гармоники и плотность (10) |
| Свинг | Смещение каждой второй восьмой или шестнадцатой позже (06) |
| Секвенция | Повтор мотива от другой ступени (05) |
| Синкопа | Акцент между долями (06) |
| Стем | Отдельная дорожка или группа дорожек, экспортированная в файл (12) |
| Стингер | Короткая музыкальная фраза-сигнал в игре (12) |
| Строй | Правило выбора частот нот: 12-TET, 19-EDO, натуральный строй (14) |
| Субдоминанта | Аккорд IV ступени, «уход из дома» (04) |
| Такт | Группа долей между двумя сильными долями (03) |
| Тембр | «Окраска» звука, по которой различают инструменты (08) |
| Темп | Скорость музыки в ударах в минуту (BPM) (03) |
| Тональность | Тоника + лад: например ре минор (03) |
| Тоника | Главная, устойчивая нота или аккорд тональности (03, 04) |
| Точки первых отражений | Места на стенах и потолке, от которых звук мониторов отражается к слушателю первым (15) |
| Трезвучие | Аккорд из трёх нот, построенный терциями (03) |
| Тритон | Интервал в 6 полутонов, самый неустойчивый (03) |
| Фильтр | Устройство, пропускающее одни частоты и срезающее другие (08) |
| Фраза | Законченная музыкальная мысль, обычно 2–4 такта (05) |
| Целенаправленная практика | Занятие с конкретной целью, концентрацией, обратной связью и выходом из зоны комфорта (01) |
| Цент | 1/100 полутона 12-TET; 1200 центов в октаве (14) |
| Чередование (interleaving) | Смешивание нескольких близких тем в одном занятии (01) |
| Эквалайзер (EQ) | Устройство для изменения громкости отдельных частот (10) |
| Язык Кадзиуры (Kajiurago) | Придуманные бессмысленные слоги, похожие на романские языки, на которых поёт хор в музыке Юки Кадзиуры (13) |

## A–Z

| Термин | Объяснение |
|---|---|
| ADSR | Attack, Decay, Sustain, Release — параметры огибающей (08) |
| ASIO | Протокол звуковых драйверов Windows с малой задержкой; руководство FL Studio рекомендует родной ASIO-драйвер звуковой карты (15) |
| BPM | Beats per minute — темп (03) |
| CC1, CC11 | MIDI-контроллеры динамики и выразительности в оркестровых библиотеках (09) |
| Clipping | Перегрузка: сигнал выше 0 dBFS обрезается (10, 11) |
| dBA | Децибелы со взвешиванием A, приближенным к чувствительности слуха; в них задан предел NIOSH 85 дБА (15) |
| dBFS | Децибелы относительно цифрового максимума (0 dBFS) (11) |
| dBTP (True Peak) | Реальный пик сигнала с учётом межсэмпловых пиков (11) |
| Dither | Добавление слабого шума при уменьшении разрядности (24 → 16 бит) (11) |
| EDO | Equal division of the octave — равномерное деление октавы (14) |
| FMOD | Middleware для игрового звука (12) |
| HPF / LPF | High-pass / Low-pass filter — обрезной фильтр низа / верха (08, 10) |
| K-System | Система Боба Каца для калибровки громкости мониторов и измерения уровня (15) |
| LFO | Low-frequency oscillator — медленный генератор модуляции (08) |
| LRA | Loudness range — разброс громкости по треку (11) |
| LUFS | Единица воспринимаемой громкости (ITU-R BS.1770) (11) |
| Middleware | Программа между музыкой и движком игры: FMOD, Wwise (12) |
| MIDI | Протокол передачи нот и команд между устройствами и программами (03, 09) |
| MTS-ESP | Протокол перестройки множества плагинов одним мастер-плагином (14) |
| Patcher | Плагин FL Studio для сборки цепочек инструментов и эффектов (14) |
| PLR | Peak-to-loudness ratio — разница пика и громкости (11) |
| Re-score | Переозвучка видео своей музыкой для портфолио (17) |
| Round robin | Чередование нескольких вариантов одного звука (08) |
| Scala (.scl / .kbm) | Форматы файлов строя и раскладки клавиш (14) |
| Send | Посыл части сигнала на отдельную дорожку (ревер, дилей) (10) |
| Sidechain | См. «Сайдчейн» |
| SPL | Sound pressure level — уровень звукового давления в дБ, измеряется шумомером (15) |
| Stem | См. «Стем» |
| Supersaw | Звук из нескольких расстроенных пил, классика EDM (08) |
| TET | Tone equal temperament — равномерно темперированный строй: 12-TET (14) |
| Underrun | Недогрузка буфера: процессор не успел подготовить звук, слышны щелчки (15) |
| Velocity | Сила нажатия клавиши, обычно влияет на громкость и тембр (06, 09) |
| VST / VST3 / CLAP | Форматы подключаемых плагинов (10) |
| Wwise | Middleware для игрового звука от Audiokinetic (12) |
