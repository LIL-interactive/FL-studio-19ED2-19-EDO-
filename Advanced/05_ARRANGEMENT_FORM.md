# 05. Форма и аранжировка: от лупа к законченному треку

Уровень: новичок и выше.

Что вы узнаете: как превратить 8-тактовый луп в полноценный трек, какие бывают формы в разных жанрах, как распределять инструменты, чтобы не было «каши», и как управлять энергией трека.

---

## 1. Главная проблема новичка: «вечный луп»

Типичная ситуация: есть классные 8 тактов, но трек не двигается дальше. Причина — нет формы и нет плана энергии.

Решение в три шага:

1. Выбрать форму (раздел 2).
2. Нарисовать кривую энергии (раздел 3).
3. Распределить элементы по секциям вычитанием (раздел 4).

---

## 2. Формы по жанрам

### 2.1 Песня (поп, рок, хип-хоп)

| Секция | Длина (тактов) | Задача |
|---|---|---|
| Интро | 4–8 | заинтересовать, задать настроение |
| Куплет 1 | 8–16 | рассказ, меньше энергии |
| Предприпев | 4–8 | нарастание напряжения |
| Припев | 8 | кульминация, главный «крючок» |
| Куплет 2 | 8–16 | развитие, новые детали |
| Предприпев | 4–8 |  |
| Припев | 8 |  |
| Бридж | 8 | контраст: новая гармония, тишина или смена ритма |
| Финальный припев | 8–16 | максимум энергии, часто модуляция |
| Аутро | 4–8 | завершение |

### 2.2 Электроника (хаус, техно, EDM)

| Секция | Длина | Задача |
|---|---|---|
| Интро | 16–32 | удобно диджею сводить: в основном ударные |
| Билдап 1 | 8–16 | нарастание: райзеры, фильтр открывается, снейр-роллы |
| Дроп 1 | 16–32 | главная часть: бас + лид + полный бит |
| Брейкдаун | 16–32 | убираем бочку, атмосфера, мелодия |
| Билдап 2 | 8–16 |  |
| Дроп 2 | 16–32 | вариация первого дропа |
| Аутро | 16–32 | для сведения диджеем |

Длины кратны 8 тактам: так структура предсказуема для слушателя и диджея.

### 2.3 Кино и игры (линейный трек)

| Часть | Доля | Задача |
|---|---|---|
| Экспозиция | 20 % | тема, мир, настроение |
| Развитие | 40 % | конфликт, вариации темы, нарастание |
| Кульминация | 20 % | максимальная энергия и громкость |
| Развязка | 20 % | возврат темы, успокоение |

### 2.4 Игровой луп

Форма A – B – A' – C или A – B – A – B'. Длина петли 1–3 минуты. Конец логически ведёт в начало (подробно — гайд 10).

### Упражнение 2.1. Карта референса

1. Возьмите трек из вашего любимого жанра и перетащите его в Playlist FL Studio.
2. Расставьте маркеры (Playlist → Add marker, Alt+T) на каждой смене секции.
3. Подпишите секции и посчитайте их длины в тактах.
4. Над референсом расположите свой проект и повторите структуру.

Этот приём используют многие профессионалы: структура почти всегда «заимствуется» из жанра, а уникальность создаётся содержанием.

## 3. Кривая энергии

Нарисуйте на бумаге график: по горизонтали — время, по вертикали — энергия (от 1 до 10). Пример для поп-песни:

| Секция | Энергия |
|---|---|
| Интро | 3 |
| Куплет | 4 |
| Пред. | 6 |
| Припев | 8 |
| Куплет 2 | 5 |
| Пред. | 7 |
| Припев | 8 |
| Бридж | 4 |
| Финал | 10 |
| Аутро | 3 |

Что повышает энергию:

- Больше инструментов (плотность).
- Выше регистр мелодии.
- Более мелкие длительности (восьмые → шестнадцатые).
- Открытие фильтра, больше высоких частот.
- Громкость, сатурация.
- Гармоническое напряжение (доминанта, модуляция вверх).

Что понижает: обратное. Главное правило — контраст. Громкий припев впечатляет только после тихого куплета.

---

## 4. Метод вычитания

Вместо того чтобы добавлять инструменты в каждую секцию, сделайте наоборот:

1. Соберите самую насыщенную секцию (припев или дроп) со всеми инструментами.
2. Скопируйте её на всю длину трека.
3. Для каждой секции удалите то, что не нужно: в куплете — лид и половину перкуссии, в интро — всё, кроме пэда и хэта, и т. д.

Так все секции гарантированно «родственны» и трек звучит цельно.

### Упражнение 4.1

Возьмите свой 8-тактовый луп. Методом вычитания сделайте из него 2-минутный трек по форме электроники (раздел 2.2).

## 5. Роли инструментов

Каждый элемент аранжировки выполняет одну роль. Одновременно активны 3–5 ролей.

| Роль | Задача | Типичные инструменты |
|---|---|---|
| Фундамент | низ, опора | бас, 808, контрабасы, левая рука фортепиано |
| Ритм | движение | ударные, перкуссия, арпеджио, гитарный ритм |
| Гармония (подложка) | аккорды, «ковёр» | пэды, струнные, фортепиано, орган |
| Главная мелодия | внимание слушателя | вокал, лид-синт, скрипка, труба |
| Контрмелодия | ответ мелодии, заполнение пауз | виолончель, второй синт, гитара |
| Краски | детали, переходы | колокольчики, FX, райзеры, вокальные чопы |

Правило: если два инструмента выполняют одну роль в одном регистре — один лишний. Либо разнесите их по октавам, либо дайте разные роли.

---

## 6. Регистры и частотные «этажи»

| Этаж | Частоты | Что там должно быть |
|---|---|---|
| Суб | 20–60 Гц | только бас/808 и низ бочки |
| Низ | 60–250 Гц | бас, тело бочки и малого |
| Нижняя середина | 250–800 Гц | тело аккордов (осторожно, тут «каша») |
| Середина | 800 Гц–3 кГц | мелодия, вокал |
| Верх | 3–8 кГц | атака, присутствие, хэты |
| Воздух | 8–20 кГц | блеск, тарелки, «воздух» вокала |

Пэд и мелодия не должны жить в одной октаве. Аккорды фортепиано и гитары лучше «развести»: одно играет ниже, другое — выше.

---

## 7. Переходы между секциями

Без переходов секции звучат «склеенными». Инструменты переходов:

| Приём | Как в FL Studio |
|---|---|
| Райзер (нарастающий шум) | Белый шум (3xOsc → Noise) + автоматизация фильтра Fruity Filter, громкости и ширины |
| Даунлифтер (падение) | Синусоида с автоматизацией питча вниз |
| Снейр-ролл | Малый барабан 1/8 → 1/16 → 1/32 за 4–8 тактов |
| Реверс-тарелка | Сэмпл тарелки → Channel settings → Reverse |
| Удар (impact) | Бочка + низкий шум + длинный ревер на первую долю новой секции |
| Тишина | Полтакта или такт полной тишины перед дропом |
| Фильтр | Fruity Filter / Fruity Love Philter: срезать низ в конце секции, вернуть на дропе |
| Fill ударных | Отдельный паттерн на последнем такте |

### Упражнение 7.1

Сделайте для одного трека 5 разных переходов из таблицы. Определите, какой подходит для каждой смены секции.

---

## 8. Аранжировка в FL Studio: практические советы

- Работайте паттернами: каждый инструмент — свой паттерн (Split by channel). Так проще включать и выключать элементы по секциям.
- Используйте маркеры в Playlist для секций.
- Цвета паттернов и дорожек по ролям (ударные красные, бас синий и т. д.).
- Для повторяющихся частей — Make unique, только когда нужно изменить копию.
- Trim/Slip-редактирование клипов в Playlist для быстрых вариаций.
- Сохраните шаблон проекта с вашими инструментами и маршрутизацией.

## 9. Разборы реальных примеров

| Произведение | Чему учит |
|---|---|
| Bastion (Darren Korb) | Ограничения рождают стиль. Даррен Корб называл стиль «acoustic frontier trip-hop»: сэмплированные биты слоями плюс акустическая гитара. По его словам, музыку приходилось делать в квартире без других музыкантов и живых барабанов. Аранжировка из немногих элементов дала узнаваемое звучание. |
| Transistor (Darren Korb) | Тот же композитор сознательно сменил палитру: вместо тёплого «фронтира» — электроника с налётом нуара и старой Европы. Палитра аранжировки — часть идентичности игры. |
| Celeste (Lena Raine) | Сочетание фортепиано и синтезаторов. Лена Рейн рассказывала, что начала добавлять фортепианные линии как метафору падающего снега, и фортепиано стало центральной частью звучания игры. |
| Hollow Knight (Christopher Larkin) | Два слоя для каждой области: «полный» и «облегчённый». В боковых зонах полный слой затихает. Аранжировка готовится сразу с расчётом на разную плотность. |

## 10. Частые ошибки

| Ошибка | Решение |
|---|---|
| Всё звучит одновременно с начала до конца | Метод вычитания, кривая энергии |
| Секции без переходов | Райзеры, fill, тишина, фильтр |
| Слишком длинное интро | Слушатель решает за 5–10 секунд: покажите главное быстро (кроме треков для диджеев) |
| Два инструмента дублируют одну роль | Разнесите по ролям или регистрам |
| Финал не отличается от начала | Добавьте новый элемент в финальной секции: контрмелодию, модуляцию, хор |
| Трек без конца (обрыв) | Аутро или финальный аккорд с хвостом ревера |

---

## 11. Итоговое задание

1. Выберите референс и сделайте его карту с маркерами.
2. Нарисуйте кривую энергии своего будущего трека.
3. Соберите самую насыщенную секцию.
4. Методом вычитания разложите трек по форме.
5. Добавьте переходы.
6. Попросите друга послушать и отметить момент, когда ему стало скучно. Исправьте это место.
