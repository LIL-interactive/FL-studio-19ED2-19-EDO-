# 02. Программа курса и план обучения на год

Что вы узнаете: какова цель курса и чему вы научитесь на каждом этапе, сколько часов занимает каждый модуль, как проверяется результат, и как разложить обучение на 12 месяцев.

## Карточка модуля

| Параметр | Значение |
|---|---|
| Уровень | все |
| Время | 30 минут на составление личного плана, 15 минут в неделю на обзор |
| Нужно знать | модуль 01 |
| Результат | личный план, расписание недели, список контрольных работ и чек-листы уровней |
| Смежные материалы | [00. Навигатор](00_NAVIGATOR.md), [01. Как учиться музыке](01_LEARNING_HOW_TO_LEARN.md) |

## Коротко о главном

- Цель курса — самостоятельно писать, сводить и выпускать музыку в FL Studio, в том числе для игр и медиа.
- Программа состоит из шести частей и приложений; каждая часть заканчивается контрольной работой.
- Обучение строится вокруг законченных работ, а не прочитанных страниц.
- Неделя: слух, повторение, новая тема, работа над треком, активное слушание.
- План можно ужать или растянуть: важна регулярность.

## 1. Цель и формат программы

| Пункт | Описание |
|---|---|
| Цель | научиться самостоятельно сочинять, аранжировать, сводить и выпускать музыку в FL Studio, включая адаптивную музыку для игр |
| Для кого | для начинающих без музыкального образования и для тех, кто пишет «по наитию» и хочет системы |
| Формат | самостоятельное обучение по модулям: теория, примеры, упражнения, итоговое задание, самопроверка |
| Объём | около 300 часов при стандартном режиме (6–7 часов в неделю, 12 месяцев) |
| Инструменты | FL Studio (21 или новее), наушники или мониторы, по желанию MIDI-клавиатура; бесплатные плагины из модуля 19 |
| Принципы | целенаправленная практика, вспоминание вместо перечитывания, интервальные повторения, обучение через законченные работы (модуль 01) |
| Политика источников | факты в модулях взяты из указанных источников; вторичные источники помечены; упражнения — учебные задания курса |

После каждой части вы должны уметь следующее.

| Часть | Модули | Результаты обучения |
|---|---|---|

| 2. Создание трека | 07–09 | собирать трек по форме жанра, создавать звуки с нуля, оркеструировать тему и программировать оркестровые библиотеки |

## 4. Календарный план на 12 месяцев

### Шаблон недели (стандартный режим)

| День | Занятие (около 60 минут) |
|---|---|
| Понедельник | слух 10 минут + новая тема модуля + упражнения |
| Вторник | слух 10 минут + упражнения + применение в треке |
| Среда | активное слушание и разбор произведения (модуль 20) |
| Четверг | слух 10 минут + новая тема + упражнения |
| Пятница | работа над треком недели |
| Суббота | работа над треком недели, экспорт |
| Воскресенье | 15 минут: «Проверь себя» по прошлым модулям, дневник, план на неделю |

Каждые две недели — один законченный трек или этюд, даже короткий.

## 5. Контрольные работы

Контрольная работа — законченное произведение, которое проверяет навыки части. Делайте её без подсказок, затем оценивайте по критериям: каждый пункт «да» или «нет». Работа зачтена, если выполнено не меньше четырёх пунктов из пяти.

### Контрольная работа 1. Пьеса на 32 такта

| Критерий |
|---|
| Последовательность аккордов выбрана под задуманную эмоцию |
| Есть мотив, который повторяется и развивается |
| Мелодия опирается на аккордовые ноты на сильных долях |
| Ударные с динамикой, не механические |
| Есть хотя бы один заимствованный аккорд или вторичная доминанта |

### Контрольная работа 2. Законченный трек 2–3 минуты

| Критерий |
|---|
| Ясная форма с контрастом секций |
| Переходы между секциями |
| Минимум три звука собраны с нуля |
| Нет двух инструментов с одной ролью в одном регистре |
| Трек закончен и экспортирован |

### Контрольная работа 3. Сведение и мастеринг

| Критерий |
|---|
| Все важные элементы слышны на телефоне |
| Нет «мути» и резкости при сравнении с референсом |
| Микс не разваливается в моно |
| Громкость в выбранной цели (например −14…−10 LUFS для стриминга) |
| True Peak не выше −1 dBTP |

### Контрольная работа 4. Мини-саундтрек или альбом

| Критерий |
|---|
| Единая звуковая палитра |
| Узнаваемая главная тема и её вариации |
| Для игры: слои работают в любой комбинации; для альбома: треки звучат цельно |
| Технические требования соблюдены (формат, громкость, лупы) |
| Работа опубликована или показана слушателям |

## 6. Чек-листы «Я умею»

Отмечайте пункт, когда можете выполнить его без подсказки.

### Уровень 1. Начинающий (после части 1)

- Найти любую ноту в Piano roll и назвать её.
- Построить мажорную и минорную гамму от любой ноты.
- Построить мажорное, минорное, уменьшённое трезвучие.
- Узнать на слух терцию, квинту и октаву.
- Запрограммировать базовый бит в 4/4.
- Экспортировать трек в WAV.

### Уровень 2. Продолжающий (после части 2)

- Подобрать на слух бас и аккорды простой песни.
- Написать последовательность под заданную эмоцию.
- Развить мотив пятью способами.
- Собрать трек по форме жанра с переходами.
- Создать бас, пэд и лид с нуля.
- Объяснить, что делают атака и релиз компрессора.

### Уровень 3. Уверенный (после части 3)

- Использовать заимствованные аккорды, вторичные доминанты, модуляции.
- Оркестровать тему для струнных, меди и деревянных.
- Свести трек так, чтобы он звучал близко к референсу.
- Сделать мастер под нужную громкость без пережатия.
- Настроить мониторы и громкость прослушивания по модулю 15.

### Уровень 4. Продвинутый (после частей 4 и 5)

- Подготовить слои адаптивной музыки и бесшовные лупы, собрать их в FMOD.
- Объяснить и применить приёмы минимум двух композиторов из модуля 13.
- Работать по брифу заказчика в срок.
- Иметь портфолио из 4–5 сильных работ и демо-ролика.

## 7. Ежемесячный обзор

В конце каждого месяца ответьте письменно:

1. Какие работы я закончил?
2. Какой навык вырос сильнее всего? Как я это понял?
3. Какая ошибка повторялась чаще всего (смотрите дневник)?
4. Что из плана не получилось и почему?
5. На чём сосредоточусь в следующем месяце?

Раз в квартал слушайте подряд свою первую и последнюю работу этапа.

---

## 8. Если план срывается

| Ситуация | Решение |
|---|---|
| Пропустил неделю | не «догоняйте», продолжайте с текущего места и сдвиньте план на неделю |
| Тема не даётся | разбейте на мелкие шаги, вернитесь к предыдущему модулю, найдите второй источник (модуль 19) |
| Пропал интерес | неделя свободного творчества без плана, затем возвращение |
| Слишком легко | пропустите упражнения, сразу делайте итоговое задание модуля |
| Мало времени | перейдите на минимальный режим: 3 часа в неделю, курс растянется примерно до двух лет |

## Проверь себя

1. Какова цель программы?
2. Сколько частей в программе и чем заканчивается каждая?
3. Сколько часов занимает курс в стандартном режиме?
4. Когда контрольная работа считается зачтённой?
5. Что делать, если пропустили неделю?
6. Какие вопросы задавать себе в ежемесячном обзоре?

### Ответы

1. Научиться самостоятельно сочинять, аранжировать, сводить и выпускать музыку в FL Studio, включая адаптивную музыку для игр.
2. Шесть частей (от 0 до 5) и приложения; каждая из частей 1–3 и итог частей 4–5 заканчиваются контрольной работой.
3. Около 300 часов.
4. Если выполнено не меньше четырёх критериев из пяти.
5. Не догонять, продолжить с текущего места и сдвинуть план.
6. Что закончил, что выросло, какие ошибки повторялись, что не получилось, на чём сосредоточиться дальше.
