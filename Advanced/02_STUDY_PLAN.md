# 02. План обучения на год и самопроверка

Что вы узнаете: как разложить курс на 12 месяцев, сколько заниматься в неделю, какие результаты должны появиться на каждом этапе и как проверить, что вы действительно продвинулись.

## Карточка модуля

| Параметр | Значение |
|---|---|
| Уровень | все |
| Время | 30 минут на составление плана, 15 минут в неделю на обзор |
| Нужно знать | модуль 01 |
| Результат | личный план, расписание недели, список контрольных работ и чек-листы уровней |
| Смежные материалы | [00. Навигатор](00_NAVIGATOR.md), [01. Как учиться музыке](01_LEARNING_HOW_TO_LEARN.md) |

## Коротко о главном

- План строится вокруг законченных работ, а не прочитанных страниц.
- Четыре этапа по три месяца: язык музыки → создание трека → звук → специализация.
- Каждую неделю: слух, повторение, новая тема, работа над треком.
- В конце каждого этапа — контрольная работа и чек-лист «Я умею».
- План можно ужать или растянуть под своё время: важна регулярность.

---

## 1. Сколько заниматься

| Режим | Время в неделю | Как пройти курс |
|---|---|---|
| Минимальный | 3 часа (5 × 35 минут) | весь курс примерно за 18–24 месяца |
| Стандартный | 6–7 часов (6 × 1 час) | за 12 месяцев (план ниже) |
| Интенсивный | 12–15 часов | за 6–8 месяцев |

Регулярность важнее объёма: 5 коротких занятий в неделю дают больше, чем одно длинное.

---

## 2. Шаблон недели (стандартный режим)

| День | Занятие (около 60 минут) |
|---|---|
| Понедельник | Слух 10 мин + новая тема модуля + упражнения |
| Вторник | Слух 10 мин + упражнения + применение в треке |
| Среда | Активное слушание и разбор референса (модуль 18) |
| Четверг | Слух 10 мин + новая тема + упражнения |
| Пятница | Работа над треком недели |
| Суббота | Работа над треком недели, экспорт |
| Воскресенье | 15 минут: «Проверь себя» по прошлым модулям, дневник, план на неделю |

Каждые две недели — один законченный трек или этюд (даже короткий, 1 минута).

---

## 3. План на 12 месяцев

### Этап 1. Язык музыки (месяцы 1–3)

| Неделя | Модули | Задание недели |
|---|---|---|
| 1 | 01, 02 | Составить план, завести дневник, установить тренажёр слуха |
| 2–3 | 03 | Упражнения 2.1–5.1, итоговое задание модуля 03 |
| 4–6 | 04 (разделы 1–5) | Библиотека из 10 своих аккордовых последовательностей в MIDI |
| 7–8 | 05 | Мотив и пять вариаций, период 8 тактов |
| 9–10 | 06 | 8 жанровых паттернов ударных |
| 11–12 | 04 (разделы 6–10) | Трек на 16 тактов с заимствованием, вторичной доминантой и модуляцией |
| 13 | повторение | Контрольная работа 1 (раздел 4) |

### Этап 2. Создание трека (месяцы 4–6)

| Неделя | Модули | Задание недели |
|---|---|---|
| 14–16 | 07 | Карта двух референсов, трек методом вычитания |
| 17–19 | 08 | Свои пресеты: суб, 808, пэд, лид, плак, вобл, чиптюн |
| 20–23 | 09 | Оркестровка темы тремя способами, мокап с CC1 |
| 24–25 | 14 | Шаблон проекта, «трек за 4 часа» |
| 26 | повторение | Контрольная работа 2 |

### Этап 3. Звук (месяцы 7–9)

| Неделя | Модули | Задание недели |
|---|---|---|
| 27–31 | 10 | Сведение мультитрека (Cambridge Music Technology) и своего трека |
| 32–34 | 11 | Мастеринг трёх треков, версия для стриминга и для игры |
| 35–38 | 10, 11 | Пересвести и перемастерить два старых трека, сравнить с оригиналом |
| 39 | повторение | Контрольная работа 3 |

### Этап 4. Специализация и портфолио (месяцы 10–12)

| Неделя | Модули | Задание недели |
|---|---|---|
| 40–44 | 12 | Мини-саундтрек: тема, слои, стингеры, FMOD-проект |
| 45–46 | 13 (по желанию) | Пьеса в 19-EDO и сравнение с 12-TET |
| 47–50 | 15 | Портфолио, переозвучка, участие в геймджеме |
| 51–52 | итог | Контрольная работа 4, обзор года, план на следующий год |

Если вы не планируете писать для игр, замените этап 4 своим направлением: альбом, работа с вокалом, библиотеки для стоков.

---

## 4. Контрольные работы

Контрольная работа — законченное произведение, которое проверяет навыки этапа. Делайте её без подсказок, затем оценивайте по критериям.

### Контрольная работа 1: «Пьеса на 32 такта»

Задание: пьеса в любом жанре, 32 такта, с аккордами, мелодией, басом и ударными.

| Критерий | Да / нет |
|---|---|
| Последовательность аккордов выбрана под задуманную эмоцию | |
| Есть мотив, который повторяется и развивается | |
| Мелодия опирается на аккордовые ноты на сильных долях | |
| Ударные с динамикой, не механические | |
| Есть хотя бы один заимствованный аккорд или вторичная доминанта | |

### Контрольная работа 2: «Законченный трек 2–3 минуты»

| Критерий | Да / нет |
|---|---|
| Ясная форма с контрастом секций | |
| Переходы между секциями | |
| Минимум три звука собраны с нуля | |
| Нет двух инструментов с одной ролью в одном регистре | |
| Трек закончен и экспортирован | |

### Контрольная работа 3: «Сведение и мастеринг»

| Критерий | Да / нет |
|---|---|
| Все важные элементы слышны на телефоне | |
| Нет «мути» и резкости при сравнении с референсом | |
| Микс не разваливается в моно | |
| Громкость в выбранной цели (например −14…−10 LUFS) | |
| True Peak не выше −1 dBTP | |

### Контрольная работа 4: «Мини-саундтрек или альбом»

| Критерий | Да / нет |
|---|---|
| Единая звуковая палитра | |
| Узнаваемая главная тема и её вариации | |
| Для игры: слои работают в любой комбинации; для альбома: треки звучат цельно | |
| Технические требования соблюдены (формат, громкость, лупы) | |
| Работа опубликована или показана слушателям | |

## 5. Чек-листы «Я умею»

Отмечайте пункты, когда можете сделать их без подсказки.

### Уровень 1. Начинающий

- Найти любую ноту в Piano roll и назвать её.
- Построить мажорную и минорную гамму от любой ноты.
- Построить мажорное, минорное, уменьшённое трезвучие.
- Узнать на слух терцию, квинту и октаву.
- Запрограммировать базовый бит в 4/4.
- Экспортировать трек в WAV.

### Уровень 2. Продолжающий

- Подобрать на слух бас и аккорды простой песни.
- Написать последовательность под заданную эмоцию.
- Развить мотив пятью способами.
- Собрать трек по форме жанра с переходами.
- Создать бас, пэд и лид с нуля.
- Объяснить, что делают атака и релиз компрессора.

### Уровень 3. Уверенный

- Использовать заимствованные аккорды, вторичные доминанты, модуляции.
- Оркестровать тему для струнных, меди и деревянных.
- Свести трек так, чтобы он звучал близко к референсу.
- Сделать мастер под нужную громкость без пережатия.
- Подготовить слои адаптивной музыки и бесшовные лупы.

### Уровень 4. Продвинутый

- Работать по брифу заказчика в сроки.
- Собрать адаптивный трек в FMOD или Wwise.
- Делать реармонизацию и кинематографическую гармонию.
- Иметь портфолио из 4–5 сильных работ и демо-ролика.

---

## 6. Ежемесячный обзор

В конце каждого месяца ответьте письменно:

1. Какие работы я закончил?
2. Какой навык вырос сильнее всего? Как я это понял?
3. Какая ошибка повторялась чаще всего (смотрите дневник)?
4. Что из плана не получилось и почему?
5. На чём сосредоточусь в следующем месяце?

Раз в квартал слушайте свою первую работу этапа и последнюю подряд.

---

## 7. Если план срывается

| Ситуация | Решение |
|---|---|
| Пропустил неделю | Не «догоняйте», продолжайте с текущего места; сократите план на 1 неделю |
| Тема не даётся | Разбейте на мелкие шаги, вернитесь к предыдущему модулю, найдите второй источник (модуль 17) |
| Пропал интерес | Сделайте неделю свободного творчества без плана, затем вернитесь |
| Слишком легко | Пропустите упражнения, сразу делайте итоговое задание модуля |
| Мало времени | Перейдите на минимальный режим (раздел 1), но не прекращайте совсем |

## Проверь себя

1. Вокруг чего строится план обучения?
2. Что важнее: объём занятий в неделю или регулярность?
3. Как часто стоит заканчивать трек или этюд?
4. Что такое контрольная работа в этом курсе?
5. Что делать, если пропустили неделю?
6. Какие вопросы задавать себе в ежемесячном обзоре?

### Ответы

1. Вокруг законченных работ, а не прочитанных страниц.
2. Регулярность.
3. Примерно раз в две недели.
4. Законченное произведение в конце этапа, оцениваемое по критериям.
5. Не догонять, продолжать с текущего места и сократить план.
6. Что закончил, что выросло, какие ошибки повторялись, что не получилось, на чём сосредоточиться дальше.
