# 14. Слух, рабочий процесс и домашняя студия

Что вы узнаете: как тренировать музыкальный слух и слух звукорежиссёра, как организовать работу так, чтобы заканчивать треки, как настроить FL Studio и как подготовить комнату и мониторинг при небольшом бюджете.

## Карточка модуля

| Параметр | Значение |
|---|---|
| Уровень | все |
| Время | постоянно, 10–15 минут в день на слух |
| Нужно знать | ничего |
| Результат | тренируете слух по плану, заканчиваете треки, настроили FL и рабочее место |
| Смежные материалы | [01. Как учиться музыке](01_LEARNING_HOW_TO_LEARN.md) |

## Коротко о главном

- Слух тренируется короткими ежедневными сессиями.
- Разделяйте режимы: сочинение, аранжировка, звук, сведение, мастеринг.
- Ограничения (время, инструменты, дорожки) ускоряют работу.
- Законченный неидеальный трек учит больше, чем десять незаконченных.
- Наушники и обработка комнаты важнее дорогих мониторов.

## 1. Два вида слуха

| Вид | Что слышит | Как тренировать |
|---|---|---|
| Музыкальный | интервалы, аккорды, лады, ритм, мелодии | тренажёры интервалов, подбор по слуху, диктанты |
| Технический (звукорежиссёрский) | частоты, громкость, компрессию, ревер, искажения | частотные тренажёры, сравнение с референсами, A/B-тесты |

Оба вида тренируются ежедневными короткими занятиями. 10–15 минут каждый день лучше, чем 2 часа раз в неделю.

## 2. Тренировка музыкального слуха

### 2.1 Программа на 8 недель

| Неделя | Задание (ежедневно 10–15 минут) |
|---|---|
| 1 | Интервалы вверх: терции, квинты, октавы |
| 2 | Все интервалы вверх |
| 3 | Все интервалы вверх и вниз |
| 4 | Мажорное, минорное, уменьшённое, увеличенное трезвучие |
| 5 | Ступени в тональности (Functional Ear Trainer) |
| 6 | Септаккорды: maj7, 7, m7, m7b5 |
| 7 | Последовательности аккордов (I–IV–V, I–V–vi–IV и т. д.) |
| 8 | Подбор мелодии и баса трёх известных песен в Piano roll |

### 2.2 Подбор по слуху в FL Studio

1. Перетащите песню в Playlist.
2. Создайте канал с фортепиано, откройте Piano roll.
3. Сначала найдите бас (самую низкую ноту) — это подскажет аккорды.
4. Затем мелодию.
5. Для сложных мест используйте Edison: выделите фрагмент, замедлите без изменения высоты (Time stretch) и зациклите.

### Упражнение 2.1

Подберите главную тему из любимой игры (например Zelda, Mario, Tetris, Undertale) в Piano roll: мелодию, бас и аккорды. Сравните с нотами из интернета.

## 3. Тренировка технического слуха

| Упражнение | Инструмент | Цель |
|---|---|---|
| Угадай частоту поднятой полосы | SoundGym, Quiztones | слышать частоты без анализатора |
| Угадай разницу громкости 1–3 дБ | SoundGym | точный баланс |
| Слышит ли компрессор | свой проект, Fruity Compressor | атака, релиз, подавление |
| Сравнение с референсом | Voxengo SPAN, ADPTR Metric AB | понимание жанровых стандартов |
| Слепой A/B | плагин Blind Test или помощь друга | честность решений |

### Упражнение 3.1. Слепой тест

Попросите друга переключать между двумя версиями вашего микса (например, с компрессором и без), выровненными по громкости. Сможете ли вы угадать в 8 случаях из 10? Если нет — разница не важна, выбирайте любой вариант.

## 4. Рабочий процесс: как заканчивать треки

### 4.1 Разделяйте режимы

| Режим | Задача | Чего не делать |
|---|---|---|
| Сочинение | идеи, мелодии, аккорды | не сводить, не выбирать пресеты часами |
| Аранжировка | форма, развитие | не шлифовать звук |
| Саунд-дизайн | звуки, пресеты | не писать новые части |
| Сведение | баланс, обработка | не менять аранжировку |
| Мастеринг | финальный звук | не возвращаться к сочинению |

Смешивание режимов — главная причина «бесконечных» проектов.

### 4.2 Ограничения ускоряют

- Ограничьте время: 2 часа на идею, 1 вечер на аранжировку.
- Ограничьте инструменты: 1 синтезатор + 1 набор ударных на трек.
- Ограничьте количество дорожек: например, не больше 16.

Пример из практики: Даррен Корб создавал музыку Bastion в квартире без других музыкантов и живых барабанов, и именно эти ограничения сформировали стиль саундтрека.

### 4.3 Принцип «закончить плохо лучше, чем не закончить»

Каждый законченный трек учит больше, чем десять незаконченных: вы проходите все этапы, от идеи до мастера. Ставьте цель — один законченный трек в неделю или две, даже если он неидеален.

### 4.4 Шаблон проекта

Сохраните проект-шаблон (File → Save as template или поместите проект в папку шаблонов):

- Ваши любимые инструменты в Channel rack.
- Дорожки микшера с шинами и send-реверами.
- Youlean Loudness Meter и анализатор на Master.
- Цвета и имена.

### 4.5 Библиотека идей

- Сохраняйте удачные аккорды и мелодии как MIDI (Piano roll → File → Export as MIDI file).
- Сохраняйте пресеты синтезаторов в свою папку.
- Записывайте голосовые идеи на телефон.

### Упражнение 4.1. Трек за 4 часа

1. Час 1 — сочинение: аккорды, мелодия, бас, ударные (8–16 тактов).
2. Час 2 — аранжировка методом вычитания (модуль 07).
3. Час 3 — сведение.
4. Час 4 — мастеринг и экспорт.

Не возвращайтесь к предыдущему этапу. Результат опубликуйте или покажите другу.

## 5. Настройка FL Studio для комфортной работы

| Настройка | Где | Рекомендация |
|---|---|---|
| Аудиодрайвер | Options → Audio settings | ASIO-драйвер звуковой карты или FL Studio ASIO |
| Буфер | там же | 128–256 сэмплов при записи, 512–2048 при сведении |
| Частота дискретизации | там же | 48 кГц для игр и видео, 44,1 кГц для музыки |
| Автосохранение | Options → File settings | включить, интервал 5–10 минут |
| Резервные копии | File → Save new version (Ctrl+N) | новая версия перед каждым большим изменением |
| Горячие клавиши | Help → Keyboard shortcuts | выучите 20 главных |

### 20 главных горячих клавиш FL Studio

| Клавиши | Действие |
|---|---|
| F5 | Playlist |
| F6 | Channel rack |
| F7 | Piano roll |
| F8 | Plugin picker (выбор плагинов) |
| F9 | Микшер |
| Пробел | Play / Stop |
| Ctrl+S | Сохранить |
| Ctrl+N | Сохранить новую версию |
| Ctrl+Z | Отменить (Ctrl+Alt+Z — многошаговая отмена) |
| Ctrl+B | Дублировать выделение |
| Ctrl+L | Привязать выбранные каналы к свободным дорожкам микшера |
| Ctrl+R | Экспорт WAV |
| Ctrl+Q (в Piano roll) | Квантизация |

Сочетания могут незначительно отличаться в разных версиях FL; проверяйте в справке (Help → Keyboard shortcuts).

## 6. Домашняя студия при небольшом бюджете

### 6.1 Приоритет покупок

| Приоритет | Что | Зачем |
|---|---|---|
| 1 | Хорошие открытые или полуоткрытые наушники | точный звук без влияния комнаты |
| 2 | Звуковая карта (аудиоинтерфейс) с ASIO | низкая задержка, качество |
| 3 | MIDI-клавиатура (25–49 клавиш) | игра, запись CC1 для оркестра |
| 4 | Акустическая обработка | без неё мониторы бесполезны |
| 5 | Мониторы | после обработки комнаты |
| 6 | Микрофон | если пишете вокал или живые инструменты |

Популярные наушники для сведения: Sennheiser HD 600 / HD 650, Beyerdynamic DT 880 / DT 990 Pro, AKG K702. Для записи — закрытые (Audio-Technica ATH-M50x, Beyerdynamic DT 770 Pro).

### 6.2 Акустика комнаты

1. Мониторы — симметрично относительно стен, образуют с головой равносторонний треугольник.
2. Твитеры на уровне ушей.
3. Не ставьте стол вплотную к стене; не сидите в центре комнаты (там часто «яма» в басу).
4. Поглотители на точках первых отражений (боковые стены, потолок над столом).
5. Басовые ловушки в углах.
6. Ковёр на полу, шторы, книжные полки — бюджетная обработка.

### 6.3 Калибровка

Программы вроде Sonarworks SoundID Reference измеряют и выравнивают звучание наушников и мониторов. Для наушников существуют профили конкретных моделей — это дешёвый способ получить точную картину.

## 7. Здоровье ушей и тела

- Уровень прослушивания 75–83 дБ SPL (громкость спокойного разговора). Бесплатные приложения-шумомеры помогут.
- Перерывы 10 минут каждые 45–60 минут.
- Уши «устают» за 2–3 часа: решения по миксу после этого ненадёжны.
- Беруши для концертов и клубов.
- Удобный стул, монитор на уровне глаз, перерывы для спины и рук.

---

## 8. Как учиться эффективно

1. Копируйте: воссоздайте трек любимого исполнителя в FL Studio как можно точнее. Это лучший способ понять приёмы.
2. Одна новая техника за раз: изучили сайдчейн — сделайте 3 трека с ним.
3. Обратная связь: показывайте работы сообществам (раздел источников) и людям, которым доверяете.
4. Читайте мануалы: FL Studio Online Manual отвечает на большинство вопросов.
5. Ведите дневник: что получилось, что нет, что изучить дальше.

### Упражнение 8.1. Копия трека

Выберите простой трек (2–3 минуты). Восстановите его в FL Studio: структуру, аккорды, мелодию, ударные, примерные звуки. Сравните результат с оригиналом и запишите 5 вещей, которые вы узнали.

## Проверь себя

Ответьте письменно или вслух, не подглядывая. Затем сверьтесь с ответами. Вопросы, на которые не ответили, повторите через 2–3 дня.

1. Сколько времени в день достаточно для тренировки слуха?
2. Почему важно разделять режимы работы?
3. Что купить в домашнюю студию в первую очередь?
4. Какой уровень громкости прослушивания безопасен для работы?
5. Как сохранить новую версию проекта в FL?
6. Как научиться приёмам любимого автора?

### Ответы

1. 10–15 минут, но каждый день.
2. Смешивание режимов — главная причина бесконечных проектов.
3. Хорошие наушники для сведения.
4. 75–83 дБ SPL.
5. Ctrl+N.
6. Воссоздать его трек в FL Studio как можно точнее.
