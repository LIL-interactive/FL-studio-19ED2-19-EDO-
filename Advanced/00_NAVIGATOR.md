# Навигатор по курсу

Курс по созданию музыки в FL Studio: от того, как учиться, и музыкальной грамоты до игровых саундтреков, сведения, мастеринга и микротональности. Написан простым языком для начинающих и доходит до профессионального уровня.

Удобнее всего читать курс в файле BOOK.html в корне репозитория: откройте его в браузере, слева будет оглавление, поиск и разделы текущего модуля. После изменения текстов книгу пересобирают командой python3 tools/build_book.py.

## 2. Как устроен каждый модуль

Все модули построены одинаково, чтобы было легко ориентироваться.

| Блок | Зачем |
|---|---|
| Что вы узнаете | Одна фраза о содержании |
| Карточка модуля | Уровень, время, что нужно знать заранее, какой результат вы получите |
| Коротко о главном | 5 ключевых мыслей — прочитайте до и после модуля |
| Разделы с теорией | Объяснения простым языком, таблицы, примеры в FL Studio |
| Примеры | Реальные произведения и разборы известных саундтреков |
| Упражнения | Короткие задания после каждого раздела |
| Частые ошибки | Что обычно идёт не так и как исправить |
| Итоговое задание | Законченная работа по теме модуля |
| Проверь себя | Вопросы с ответами для повторения через 2–3 дня |
| Что дальше | Следующий модуль |
| Источники | Книги, курсы, интервью |

Почему так: по данным когнитивной психологии знания лучше закрепляются, когда вы вспоминаете их сами и сразу применяете (подробно — в модуле 01).

## 7. Условные обозначения

| Обозначение | Значение |
|---|---|
| C4 | Научная запись: центральная до (MIDI 60). В FL Studio эта нота подписана C5 |
| A4 = 440 Гц | Эталон настройки (в инструментах репозитория можно выбрать 437 Гц) |
| I, IV, V | Мажорные аккорды на ступенях тональности |
| ii, iii, vi | Минорные аккорды на ступенях тональности |
| vii° | Уменьшённый аккорд |
| bVI, bVII | Аккорды на пониженных ступенях (заимствованные из минора) |
| дБ, LUFS, dBTP | Единицы уровня и громкости (модуль 11) |
| Options → Audio settings | Путь в меню FL Studio |
| Упражнение 3.1 | Упражнение к разделу 3 текущего модуля |
| Модуль 04, раздел 6 | Ссылка на другой модуль курса |

Названия меню FL Studio приведены для версий 21, 2024 и 2025; в других версиях пункты могут немного отличаться. Факты из интервью приведены в пересказе — для цитирования сверяйтесь с первоисточниками (список в модуле 17).
