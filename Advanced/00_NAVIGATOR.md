# Навигатор по курсу

Курс по созданию музыки в FL Studio: от того, как учиться, и музыкальной грамоты до игровых саундтреков, разборов японских композиторов, сведения, мастеринга, оборудования студии и микротональности. Написан простым языком для начинающих и доходит до профессионального уровня.

Удобнее всего читать курс в файле BOOK.html в корне репозитория: откройте его в браузере, слева будет оглавление, поиск и разделы текущего модуля. После изменения текстов книгу пересобирают командой python3 tools/build_book.py.

## 2. Как устроен каждый модуль

| Блок | Зачем |
|---|---|
| Что вы узнаете | одна фраза о содержании |
| Карточка модуля | уровень, время, что нужно знать заранее, какой результат вы получите |
| Коротко о главном | 5 ключевых мыслей — прочитайте до и после модуля |
| Разделы с теорией | объяснения простым языком, таблицы, примеры в FL Studio |
| Примеры | реальные произведения, интервью и разборы |
| Упражнения | короткие задания после разделов |
| Частые ошибки | что обычно идёт не так и как исправить |
| Итоговое задание | законченная работа по теме модуля |
| Проверь себя | вопросы с ответами для повторения через 2–3 дня |
| Что дальше | следующий модуль |
| Источники | книги, документация, исследования, интервью |

Почему так: знания лучше закрепляются, когда вы вспоминаете их сами и сразу применяете (модуль 01).

## 3. Политика источников

| Правило | Как это выглядит в курсе |
|---|---|
| Факты — только из источников | цифры, стандарты, биографии и слова композиторов сопровождаются ссылками в разделе «Источники» модуля |
| Вторичные источники помечены | фанатские сайты, блоги и пересказы отмечены словом «вторичный» |
| Расхождения не скрываются | если источники противоречат друг другу, приводятся оба варианта (например, число премий JASRAC у Таканаси) |
| Упражнения отделены от фактов | этюды «в духе» композитора — учебные задания курса, а не описание его метода |
| Учебный дизайн | часы, критерии контрольных работ и календарь в модуле 02 — решения этого курса, а не внешние данные |
| Цитаты | слова из интервью приводятся в пересказе; для цитирования сверяйтесь с первоисточником |

## 8. Условные обозначения

| Обозначение | Значение |
|---|---|
| C4 | научная запись: центральная до (MIDI 60); в FL Studio эта нота подписана C5 |
| A4 = 440 Гц | эталон настройки (в инструментах репозитория можно выбрать 437 Гц) |
| I, IV, V | мажорные аккорды на ступенях тональности |
| ii, iii, vi | минорные аккорды на ступенях тональности |
| vii° | уменьшённый аккорд |
| bVI, bVII | аккорды на пониженных ступенях (заимствованные из минора) |
| дБ, дБА, LUFS, dBTP, SPL | единицы уровня и громкости (модули 11 и 15) |
| Options → Audio Settings | путь в меню FL Studio |
| Упражнение 3.1 | упражнение к разделу 3 текущего модуля |
| Модуль 04, раздел 6 | ссылка на другой модуль курса |
| «Вторичный» | источник не первичный (фан-сайт, блог, пересказ) |

Названия меню FL Studio приведены для версий 21, 2024 и 2025; в других версиях пункты могут немного отличаться.
