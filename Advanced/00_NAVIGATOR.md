# Навигатор по курсу Advanced

Курс по созданию музыки в FL Studio: от музыкальной грамоты до игровых саундтреков, сведения, мастеринга и микротональности. Написан простым языком для начинающих, но доходит до профессионального уровня. Каждая тема содержит теорию, реальные примеры и упражнения.

## 1. Как пользоваться курсом

1. Если вы новичок — идите по маршруту «С нуля» (раздел 3). Гайды 01–05 рассчитаны на тех, кто никогда не изучал музыку.
2. Если у вас есть опыт — откройте раздел 4 «Быстрый поиск по задаче» и переходите сразу к нужной теме.
3. Каждый гайд устроен одинаково: что вы узнаете → теория → примеры → упражнения → частые ошибки → итоговое задание → источники.
4. Делайте упражнения. Чтение без практики даёт мало: 15 минут практики полезнее часа чтения.
5. Незнакомое слово — ищите в словаре [14_GLOSSARY.md](14_GLOSSARY.md).

## 3. Маршруты обучения

### 3.1 С нуля (3–4 месяца)

| Этап | Гайды | Результат |
|---|---|---|
| 1. Грамота | 01, 11 (раздел о слухе) | понимаете ноты, аккорды, ритм; начали тренировать слух |
| 2. Сочинение | 02 (разделы 1–5), 03, 04 | пишете 8–16 тактов с аккордами, мелодией и ударными |
| 3. Законченный трек | 05, 07 (разделы 1–4) | собираете полноценный трек 2–3 минуты со своими звуками |
| 4. Звук | 08, 09 | сводите и мастерите трек до уровня площадок |
| 5. Практика | 11 (рабочий процесс) | заканчиваете по треку в 1–2 недели |

## 6. Условные обозначения и соглашения

| Соглашение | Значение |
|---|---|
| C4 | научная запись: центральная до (MIDI 60). В FL Studio эта нота подписана C5 |
| A4 = 440 Гц | эталон настройки (в инструментах репозитория можно выбрать 437 Гц) |
| I, IV, V | мажорные аккорды на ступенях тональности |
| ii, iii, vi | минорные аккорды на ступенях тональности |
| vii° | уменьшённый аккорд |
| bVI, bVII | аккорды на пониженных ступенях (заимствованные из минора) |
| дБ, LUFS, dBTP | единицы уровня и громкости (см. гайд 09) |
| Пути в FL Studio | записаны через стрелку: Options → Audio settings |
| Упражнение N.M | упражнение к разделу N гайда |

Названия меню FL Studio приведены для версий 21, 2024 и 2025. В других версиях пункты могут немного отличаться.
