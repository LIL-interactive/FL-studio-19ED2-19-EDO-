## 1. Базовые понятия

| Термин | Что это простыми словами | Зачем нужно |
|---|---|---|
| dBFS | Уровень сигнала относительно цифрового максимума. 0 dBFS — потолок, выше — цифровой клиппинг. | Следим, чтобы ничего не «перевалило» за 0. |
| Peak (Sample Peak) | Самый высокий отсчёт сигнала. Именно его показывают индикаторы микшера FL. | Контроль перегрузки на дорожках. |
| True Peak (dBTP) | Реальный пик между отсчётами, когда ЦАП или кодек (MP3/AAC/Ogg) восстанавливает волну. Может быть на 0,5–3 dB выше Sample Peak. | Если True Peak > −1 dBTP, после сжатия в MP3/AAC/Ogg появятся искажения. |
| RMS | Средний уровень энергии за короткое окно. Старый способ оценки громкости. | Грубая оценка плотности. |
| LUFS (LKFS) | Громкость как её слышит человек (ITU-R BS.1770: с частотным взвешиванием K и «гейтом», отбрасывающим тишину). 1 LU = 1 dB. | Главная единица — по ней площадки выравнивают треки. |
| Integrated LUFS (I) | Средняя громкость всего трека от начала до конца. | Её сравнивают с целевым значением площадки. |
| Short-term LUFS (S) | Громкость за последние 3 секунды. | Удобно смотреть громкость припева или дропа. |
| Momentary LUFS (M) | Громкость за последние 0,4 секунды. | Быстрые всплески. |
| LRA (Loudness Range) | Разница между тихими и громкими частями трека в LU. | Динамика формы трека: эмбиент — 8–15 LU, EDM — 3–6 LU. |
| PLR / PSR | Peak-to-Loudness Ratio — разница True Peak и громкости (I или S). | Насколько «живые» транзиенты. PLR < 8 обычно звучит пережато. |
| Crest factor | Отношение пика к RMS. | Тот же смысл, что у PLR. |
| Headroom | Запас между текущим пиком и 0 dBFS. | Нужен на шине и перед мастерингом. |

### Что делает нормализация громкости

Spotify, YouTube, Apple Music и другие площадки автоматически приглушают громкие треки до своего целевого уровня (а некоторые и поднимают тихие). Поэтому:

- «Перекачанный» до −6 LUFS мастер на Spotify станет тише на 8 dB. Громче он не прозвучит — только площе и грязнее, чем трек на −12 LUFS с живыми ударными.
- Мастер на −14 LUFS не теряет ничего.
- Вывод: громкость — это выбор жанра и звучания. Гнаться за ней ради площадки не нужно. Цель — не быть заметно тише цели и не пережимать.

## 2. Целевые значения

### 2.1 Стриминг (музыка)

| Площадка | Цель нормализации | True Peak | Особенности |
|---|---|---|---|
| Spotify | −14 LUFS (Normal); Loud −11; Quiet −19 | ≤ −1 dBTP; если мастер громче −14 — ≤ −2 dBTP | Тихие треки поднимает, но только в пределах запаса по пику. Альбом нормализуется целиком. В веб-плеере нормализации нет. |
| YouTube / YouTube Music | ≈ −14 LUFS | ≤ −1 dBTP | Только приглушает громкие, тихие не поднимает. |
| Apple Music (Sound Check) | ≈ −16 LUFS | ≤ −1 dBTP | Для Apple Digital Masters рекомендуют ≤ −1 dBTP. |
| Amazon Music | ≈ −14 LUFS | ≤ −1…−2 dBTP |  |
| Tidal | ≈ −14 LUFS | ≤ −1 dBTP |  |
| Deezer | ≈ −15 LUFS | ≤ −1 dBTP |  |
| SoundCloud | нормализации нет | ≤ −1 dBTP | Громкость = как сделали; принято −9…−12 LUFS для электроники. |
| Bandcamp | нормализации нет | ≤ −1 dBTP | Загружайте WAV/FLAC. |
| VK Музыка / Яндекс Музыка | официальных публичных чисел нет; на практике −14…−11 LUFS звучат нормально | ≤ −1 dBTP | Лучше ориентироваться на −14…−10 LUFS и проверять на месте. |

### 2.2 Ориентиры по жанрам (Integrated, мастер для релиза)

Это ориентиры практики, а не стандарт. Чем громче, тем меньше динамики.

| Жанр | Типичная громкость | Типичный PLR |
|---|---|---|
| Классика, оркестр, кино-оркестр | −23…−16 LUFS | 15–22 |
| Джаз, акустика, эмбиент | −18…−14 LUFS | 12–18 |
| Поп, инди, рок | −12…−9 LUFS | 9–12 |
| Хип-хоп, трэп | −10…−7 LUFS | 7–10 |
| EDM, дабстеп, хардстайл | −9…−6 LUFS | 6–9 |
| Lo-fi | −14…−11 LUFS | 10–14 |

Безопасная универсальная цель для стриминга: −14…−10 LUFS integrated, True Peak ≤ −1 dBTP (а при громче −14 LUFS лучше −2 dBTP).

### 2.3 Вещание, кино, подкасты

| Стандарт | Цель | True Peak |
|---|---|---|
| EBU R128 (Европа, ТВ/радио) | −23 LUFS ±0,5 LU | ≤ −1 dBTP |
| ATSC A/85 (США, ТВ) | −24 LKFS ±2 | ≤ −2 dBTP |
| Netflix (диалог-гейт) | −27 LKFS ±2 (по диалогу) | ≤ −2 dBTP |
| Подкасты (Apple, Spotify) | −16 LUFS (стерео), −19 (моно) | ≤ −1 dBTP |
| Кинотеатр | калибровка зала (85 dB SPL), LUFS как цель не задаётся | — |

### 2.4 Игры

| Платформа | Ориентир | True Peak | Источник |
|---|---|---|---|
| Консоли / ПК (весь микс игры) | −24 LUFS ±2 (иногда −23) | ≤ −1 dBTP | Sony ASWG-R001, позже совпавшие рекомендации Microsoft и Nintendo |
| Портативные / мобильные | −18 LUFS ±2 (часто −16…−14 на мобилках) | ≤ −1 dBTP | ASWG (PS Vita), практика мобильной индустрии |
| Отдельный музыкальный файл (stem/loop для движка) | не нормализуют под LUFS: оставляют запас (пики −3…−6 dBFS), финальный баланс задаётся в FMOD/Wwise/движке | ≤ −1 dBTP | практика |

Замеряют весь игровой микс (музыка + SFX + диалоги) минимум 30 минут типичного геймплея. Поэтому музыку для игр обычно мастерят тише и динамичнее, чем музыку для Spotify. Подробно — в [02_GAME_MUSIC_COMPOSITION_RU.md](02_GAME_MUSIC_COMPOSITION_RU.md#10-технические-требования-к-игровой-музыке).

## 3. Как замерять громкость в FL Studio

У FL нет встроенного интегрального LUFS-метра в стоковом наборе (Wave Candy и Spectroman показывают пики, RMS и спектр). Поэтому:

1. Установите Youlean Loudness Meter 2 (бесплатный, VST/VST3/AU) — стандарт де-факто.
2. Поставьте его последним в слот Master (после лимитера).
3. В Youlean выберите пресет цели (Spotify, YouTube, EBU R128 и т. д.) — он подсветит отклонения.
4. Нажмите Play с начала трека и дослушайте до конца: Integrated LUFS считается только за весь проигрыш. Удобнее — Offline: Youlean Pro умеет анализировать файл, бесплатная версия — проигрывание.
5. Смотрите:
   - Integrated — главное число;
   - True Peak Max — не выше −1 dBTP;
   - LRA — динамика формы;
   - PLR — «живость».

Альтернативы: Melda MLoudnessAnalyzer (бесплатно в MFreeFXBundle), iZotope Insight 2, NUGEN VisLM/MasterCheck, Waves WLM Plus, ADPTR Metric AB (сравнение с референсом + LUFS).

Важно про Master-фейдер FL: метры FL показывают Sample Peak. Красный индикатор = пик ≥ 0 dBFS. Внутри FL (32-бит float) перегруз не «ломает» звук, пока сигнал не дошёл до выхода или экспорта. На выходе Master пики всегда должны быть < 0 dBFS.

## 4. Подготовка проекта

1. Частота дискретизации: Options → Audio settings → 48 000 Hz (видео, игры) или 44 100 Hz (музыка). Определитесь до начала работы.
2. Буфер: при записи — маленький (128–256 сэмплов), при сведении — большой (1024–2048), чтобы тянуть тяжёлые плагины.
3. Gain staging (уровни):
   - каждая дорожка — пики около −12…−6 dBFS, средний уровень около −18 dBFS RMS (≈ 0 VU) — так работают аналоговые эмуляции;
   - Master до мастеринга — пики −6…−3 dBFS, без лимитера;
   - в FL удобно: Channel rack → громкость канала или Fruity Balance первым слотом микшера.
4. Маршрутизация в микшер: каждый инструмент — в свою дорожку (Channel settings → FX или Ctrl+L при выбранных каналах — привязка к свободным дорожкам).
5. Группы (шины): Drums, Bass, Music/Synth, Vocals, FX → по одной дорожке-шине на группу. Маршрут: правый клик на треугольнике под дорожкой → Route to this track only.
6. Цвета и имена дорожек — экономят часы.
7. Референсы: импортируйте 2–3 готовых трека того же жанра на отдельную дорожку, отправленную сразу в выход (без мастер-цепочки), и сравнивайте на одинаковой громкости LUFS (ADPTR Metric AB, Youlean или просто по уровню).
8. Мониторинг: работайте на постоянной, откалиброванной громкости (система K-System Боба Каца) и не превышайте безопасное время по рекомендации NIOSH: 85 дБА — 8 часов, каждые +3 дБА — вдвое меньше (подробно — Advanced/15_STUDIO_SETUP.md). Слушайте также на телефоне, в наушниках-«затычках» и в машине.

## 5. Сведение по шагам

### 5.1 Порядок работы

1. Статический баланс — только фейдеры и панорама, без плагинов. 70 % результата здесь.
   Начинайте с главного элемента (вокал / кик+бас / лид), остальные подстраивайте под него.
2. Чистка (коррекционный EQ): срезать лишний низ (HPF) у всего, что не бас и не бочка; убрать резонансы.
3. Динамика: компрессия, транзиенты, сайдчейн.
4. Тональный (творческий) EQ: придать характер.
5. Пространство: reverb, delay, ширина стерео.
6. Автоматизация: громкость по частям, «оживление».
7. Шины: клей на группах (bus-compression).
8. Проверка в моно, на разных системах и с референсом.

### 5.2 Частотная карта (куда смотреть)

| Диапазон | Что там | Проблема при избытке | Что делать |
|---|---|---|---|
| 20–40 Hz (суббас) | вибрация, «тело» 808 | гул, съедает громкость | HPF на всём кроме суба/кика; моно |
| 40–100 Hz (бас) | кик, бас | «бубнёж», конфликт кик/бас | разнести по частотам и сайдчейн |
| 100–300 Hz (низкая середина) | теплота, тело | «муть» — главная беда любительских миксов | вырезы −2…−4 dB на подложках |
| 300–800 Hz | «коробка», дерево | картон, коробочность | узкие вырезы |
| 800 Hz–2 kHz | атака, «нос» | гнусавость, «телефон» | аккуратно |
| 2–5 kHz | разборчивость, присутствие | резкость, утомляемость (ухо наиболее чувствительно) | динамический EQ, soothe |
| 5–10 kHz | яркость, сибилянты (с, ш) | шипение | де-эссер |
| 10–20 kHz | «воздух» | стеклянность | полка +1…+2 dB на вокал/мастер |

### 5.3 EQ — как пользоваться (Fruity Parametric EQ 2)

- Сначала вырезать, потом поднимать. Вырезы узкие (Q 4–10), подъёмы широкие (Q 0,5–1,5).
- Поиск резонанса: поднять узкую полосу на +10 dB, провести по спектру, найти «свистящую» частоту, затем опустить её на −3…−6 dB.
- HPF (обрезной фильтр): в Parametric EQ 2 — полоса 1, тип «High pass». Для вокала ~80–120 Hz, для гитар ~80–100 Hz, для пэдов и синтов 150–300 Hz.
- Не EQ'ьте в соло: важно, как дорожка звучит в миксе.
- Dynamic EQ (TDR Nova, FabFilter Pro-Q) — EQ, работающий только при превышении порога. Идеален для резкости 2–5 kHz и гула.

### 5.4 Компрессия — понятно

| Параметр | Что делает | Стартовые значения |
|---|---|---|
| Threshold | Порог, выше которого начинается сжатие | чтобы GR (подавление) было 2–6 dB |
| Ratio | Насколько сильно жмём: 4:1 — на каждые 4 dB выше порога выходит 1 dB | вокал 3–4:1; шина 2:1; бас 4–6:1 |
| Attack | Как быстро компрессор срабатывает | медленный (10–30 мс) сохраняет удар; быстрый (0,1–3 мс) срезает пики |
| Release | Как быстро отпускает | в темп трека — «дышит» вместе с грувом |
| Knee | Плавность включения | soft для вокала/шины |
| Makeup/Gain | Вернуть громкость | сравнивайте on/off на одной громкости |

Плагины FL: Fruity Compressor (простой), Fruity Limiter (режим COMP — полноценный компрессор, плюс Noise gate и sidechain), Maximus (многополосный), Transient Processor (атака/сустейн, плагин Image-Line, покупается отдельно).

Параллельная (New York) компрессия: отправьте ударные в отдельную дорожку (send), сожмите её очень сильно (10:1, −10…−15 dB GR) и подмешайте к оригиналу на −10…−15 dB. Получится плотность без потери удара.

### 5.5 Сайдчейн (кик «пробивает» бас)

Вариант A — Fruity Limiter:
1. На дорожке баса — Fruity Limiter → режим COMP.
2. На дорожке кика: правый клик на стрелке маршрута к дорожке баса → Sidechain to this track.
3. В Limiter у баса выберите SIDECHAIN = номер дорожки кика. Ratio 4–10:1, Threshold — до 3–6 dB GR, Release 50–150 мс.

Вариант B — Fruity Peak Controller: кик → Peak Controller (без звука), его выход линкуется (Link to controller) на громкость баса с инвертированной кривой.

Вариант C — LFOTool / Kickstart / Gross Beat / VolumeShaper: «огибающая громкости» по сетке — самый предсказуемый вариант для EDM.

### 5.6 Низ: кик и бас

- Решите, кто главный в суб-диапазоне: короткий кик + длинный бас или длинный 808 + короткий щелчок.
- Сверяйте тональность кика и 808 с тональностью трека (Pitcher/NewTone, или настройка Pitch в сэмплере).
- Всё ниже ~120 Hz — в моно: Frequency Splitter или Maximus разделяет полосы, низкую полосу сводим в моно Fruity Stereo Shaper; либо одним плагином — Ozone Imager, bx_stereomaker, Voxengo MSED.
- Сатурация баса (Fruity Blood Overdrive, Fruity Waveshaper, Decapitator, Saturn) добавляет гармоники, и бас слышно даже на телефоне.

### 5.7 Пространство

- Reverb и delay — через send-шины (одна-две общие ревер-дорожки), а не в каждой дорожке. В FL: дорожка → правый клик на треугольнике к шине → Route to this track (уровень посыла — ручка на треугольнике).
- На ревер-шине: EQ до ревера — HPF 200–400 Hz и LPF 8–12 kHz. Ревер без мутного низа.
- Pre-delay 10–40 мс отделяет источник от хвоста (вокал остаётся спереди).
- Плагины FL: Fruity Reeverb 2, Fruity Convolver (импульсы реальных залов), Fruity Delay 3, Fruity Delay Bank.
- Глубина: «дальше» = тише + меньше высоких + больше ревера, меньше pre-delay.

### 5.8 Стерео и панорама

- По центру: кик, бас/808, снейр, лид-вокал, главный лид.
- По бокам: хэты, перкуссия, дабл-треки гитар/вокала (L100/R100), пэды.
- Расширители (Fruity Stereo Enhancer, Stereo Shaper) — осторожно, всегда проверяйте моно. Создайте на Master кнопку моно: Fruity Stereo Shaper с пресетом Mono и включайте его для проверки.
- Фазовая корреляция (Wave Candy → Vectorscope / Correlation): должна быть преимущественно положительной (> 0).

### 5.9 Вокал (стандартная цепочка)

1. Чистка (Edison: шумы, вдохи), тюнинг — NewTone (по нотам) или Pitcher (в реальном времени).
2. Fruity Parametric EQ 2: HPF 80–120 Hz, вырез «мути» 200–400 Hz.
3. Компрессор 1 (быстрый, срезает пики) → компрессор 2 (медленный, выравнивает) — по 2–4 dB GR.
4. De-esser: Maximus (сжатие только верхней полосы 5–10 kHz, есть готовые de-ess пресеты), TDR Nova (динамическая полоса), или FabFilter Pro-DS / Waves DeEsser.
5. Тональный EQ: присутствие 3–5 kHz, воздух 10–12 kHz.
6. Send в reverb/delay.
7. Автоматизация громкости по фразам до компрессора (Clip gain/громкость в Playlist) — самый «прозрачный» способ.

### 5.10 Автоматизация в FL

- Правый клик на любом параметре → Create automation clip.
- Для микса особенно полезно: громкость в куплете и припеве, посылы на ревер в концах фраз, фильтры в билдапах.
- Fruity Formula Controller / Patcher — сложные связки параметров.

## 6. Мастеринг по шагам

### 6.1 Принципы

- Мастеринг не исправляет плохой микс. Если что-то сильно не так (> 3 dB EQ) — вернитесь в микс.
- Все изменения маленькие: EQ ±0,5…2 dB, компрессия 1–2 dB GR.
- Сравнивайте на одинаковой громкости. Громче всегда «кажется лучше». Используйте компенсацию уровня (auto gain в Ozone/Pro-L, или ADPTR Metric AB).
- Лучше делать мастеринг в отдельном проекте: экспортируйте микс в WAV 32-bit float (пики −6…−3 dBFS) и откройте в новом проекте или в Edison.

### 6.2 Типичная цепочка на Master (FL Studio)

| № | Плагин (FL) | Альтернатива VST | Зачем | Стартовые значения |
|---|---|---|---|---|
| 1 | Fruity Parametric EQ 2 | FabFilter Pro-Q, TDR Nova | Коррекция: HPF 20–30 Hz, вырезы гула/резкости | ±0,5…2 dB |
| 2 | Maximus | TDR Kotelnikov, Ozone Dynamics | Контроль низа и резких верхов | 1–2 dB GR на полосу |
| 3 | Fruity Compressor / Fruity Limiter (COMP) | SSL-type Bus Comp, Kotelnikov, Glue | «Склейка» | Ratio 1,5–2:1, Attack 10–30 мс, Release auto/100–300 мс, 1–2 dB GR |
| 4 | Сатурация: Fruity Soft Clipper, Waveshaper, Soundgoodizer (аккуратно, mix 10–30 %) | FabFilter Saturn, Softube Tape, Kclip | Плотность и гармоники | минимально |
| 5 | Fruity Stereo Shaper | Ozone Imager | Моно низа, лёгкое расширение верха | моно < 120 Hz |
| 6 | Тональный EQ | Pultec-эмуляции, Baxandall | «Воздух», финальный тон | ±0,5…1 dB, широкие полки |
| 7 | Fruity Limiter / Maximus | FabFilter Pro-L 2, Ozone Maximizer, LoudMax (бесплатный) | Громкость + потолок | Ceiling −1,0 dBTP (−2 при громком мастере), GR 2–6 dB |
| 8 | Youlean Loudness Meter 2 | Insight, VisLM | Контроль LUFS/TP | — |
| 9 | Wave Candy / Spectroman | Voxengo SPAN (бесплатный) | Спектр, фаза | — |

### 6.3 Как попасть в нужное число LUFS

1. Поставьте лимитер с Ceiling −1 dBTP (в Fruity Limiter нет True Peak-режима — оставьте −1,5…−2 dB на Ceiling, чтобы с запасом; в Pro-L 2, Ozone и LoudMax включите True Peak/ISP).
2. Поднимайте Gain (вход) лимитера, пока Integrated LUFS в Youlean не достигнет цели.
3. Если для цели нужно больше 6 dB подавления на лимитере, звук начнёт «качать» и сплющиваться. Тогда распределите громкость по цепочке: клиппер (1–2 dB) → компрессор (1–2 dB) → лимитер (2–4 dB). Или вернитесь в микс и уберите лишние пики (транзиенты отдельных дорожек, перегруз в 2–5 kHz, лишний низ).
4. Проверьте True Peak после экспорта в MP3/AAC (можно прогнать экспорт снова через Youlean).

### 6.4 Мастеринг альбома/EP

- Треки должны звучать ровно по ощущению, а не по цифре: баллада может быть на 2–3 LU тише боевика (Spotify и Apple при альбомной нормализации сохраняют эту разницу).
- Единая цепочка с подстройкой под каждый трек; паузы и fade между треками — в одном проекте FL на одной Playlist-дорожке.

### 6.5 Автомастеринг

- FL Cloud Mastering (ИИ-мастеринг, появился в FL Studio 21.2; часть функций FL Cloud требует подписки): быстро, для черновиков и демо.
- iZotope Ozone — Master Assistant: хорошая отправная точка, затем правите вручную.
- LANDR, eMastered, BandLab Mastering — онлайн-сервисы.
- Используйте как референс, не как финальное решение для важного релиза.

## 7. Экспорт из FL Studio

File → Export → WAV/MP3/OGG/FLAC (Ctrl+R).

| Настройка | Мастер для дистрибуции | Микс на мастеринг | Для игры (движок) |

| Resampling quality | 512-point sinc | 512-point sinc | 512-point sinc |
| Dither | Включён при 16-bit (для 24-bit — по желанию) | Выключен | как в ТЗ |

## 8. Чек-лист перед релизом

- Integrated LUFS в целевом диапазоне (стриминг: −14…−9; игры: см. раздел 2.4)
- True Peak ≤ −1 dBTP (≤ −2 при мастере громче −14 LUFS)
- PLR ≥ 8 (если только жанр сознательно не требует меньшего)
- Микс в моно не разваливается, бас и вокал не пропадают
- Нет щелчков в начале/конце, fade-out не обрывается
- Проверено: студийные мониторы, наушники, телефон, машина / Bluetooth-колонка
- Сравнено с 2–3 референсами на одинаковой громкости
- Нет клиппинга на экспорте (Edison → проверка пиков)
- Метаданные: исполнитель, название, ISRC (выдаёт дистрибьютор)
- Отдохнувшие уши: последний прослух — на следующий день

## 10. Частые ошибки

| Ошибка | Как исправить |
|---|---|
| Мастер громче −7 LUFS «для стриминга» | Площадка всё равно приглушит. Сделайте −10…−14 LUFS с живыми ударными. |
| Ceiling лимитера 0 dB или −0,1 dB | −1 dBTP (с True Peak-режимом) или −1,5…−2 dB в Fruity Limiter. |
| Лимитер на Master с начала работы | Сводите без него (или в bypass), с запасом −6 dB. |
| Мутный микс | Срежьте 150–400 Hz на подложках, HPF всё лишнее. |
| Резкий, утомляющий звук | Динамический EQ / Soothe на 2–5 kHz, меньше сатурации. |
| Бас «пропадает» на телефоне | Сатурация баса (гармоники 100–400 Hz). |
| Всё широкое, моно разваливается | Моно ниже 120 Hz, проверка Stereo Shaper → Mono. |
| Сравнение «до/после» без выравнивания громкости | Выравнивайте громкость при сравнении, иначе «громче = лучше». |
| Сведение на высокой громкости часами | Калибровка громкости по K-System, контроль времени по NIOSH (Advanced/15_STUDIO_SETUP.md) |
